# Legalio — Everything connected

A 15-second motion graphics introduction for the GitHub README, based on the
public [Legalio website](https://legalio.web.id/) and the repository's documented
features. The product panels are animated illustrations with fictional examples,
not recordings of customer data.

- **[Watch / download the film](legalio-intro.mp4)** — 1920 × 1080, 30 fps, H.264 video with AAC stereo audio.
- **[Animated preview](legalio-preview.gif)** — 800 × 450, 12 fps, silent loop for inline README display.
- **[Static poster](legalio-poster.png)** — an alternative to the animated preview.

The README links the animated preview to the MP4; music and sound effects are in
the MP4 only. The image and video paths are relative, so they work on any branch
that contains these assets. There is no dependency on a third-party video host.

## Audio and assets

The soundtrack is an original 120 BPM electronic instrumental synthesized for
the film: warm chords, plucked arpeggios, bass, kick, clap and hats.
Swept transition effects, UI chimes and a closing sonic signature are mixed into
the same track. No third-party music recordings or sound-effect samples are used.
There is no voice-over; the complete message appears on screen.

The film uses the existing Legalio logo files from
`packages/platform-console/src/assets/`. Text is set in Plus Jakarta Sans
(SIL Open Font License).
